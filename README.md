# Многофункциональный чат
Данное приложение было разработано во время прохождения backend-практикума в компании SimbirSoft.

## Используемые технологии:
- Java 8
- Spring Framework (Spring Boot, Spring Web, Spring JPA, Spring Security, Spring DevTools, Spring Websocket)
- Thymeleaf
- Maven
- Bootstrap
- Liquibase
- YouTube API
